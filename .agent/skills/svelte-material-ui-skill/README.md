# Svelte Material UI Skill Pack

Agente skill y referencias prácticas para Svelte 5 + Svelte Material UI (SMUI).

- `SKILL.md`: instrucciones principales del agente.
- `references`: instalación, theming, migración, catálogo, patrones, checklist y fuentes oficiales.
- `examples`: ejemplos Svelte 5, TypeScript y Sass adaptados a Clean Architecture.

Revisado el 2026-11-07. Verifica siempre las APIs contra la versión instalada y el lockfile del proyecto.
