# Legacy Monolith Archive

Este directorio contiene los archivos del monolito web original de InteresIt antes de la migración completa a Svelte 5, Svelte Material UI y Clean Architecture (Fase 9).

## Contenido archivado:
- `index.html`: Monolito Vanilla HTML/JS original (669 líneas) con persistencia IndexedDB inline, Tailwind vía CDN y cálculo financiero inicial.
- `sw.js`: Service worker básico original.
- `manifest.json`: Manifiesto PWA original del monolito.

> [!NOTE]
> Estos archivos se mantienen únicamente como referencia histórica y caracterización de paridad funcional. No son utilizados por el build, tests ni el despliegue moderno de la aplicación.
